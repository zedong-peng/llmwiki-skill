# Search and Retrieval

Use native retrieval or the bundled [paper-search tools](paper-search/README.md)
as needed. They expose search and authentication; downloads use the agent's
browser or download tools. A supplied reference may need no discovery search.

Verify references against traceable sources such as the paper itself, publisher,
repository, or scholarly index. Model recall supplies leads, not verification.
Resolve metadata differences where possible and state remaining uncertainty.
